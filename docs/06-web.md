# 06. Веб-интерфейс

Один веб-интерфейс для всех: переводчик, тайпер и клинер имеют одинаковые возможности (переводить, комментировать, ставить флажки, отмечать «затайплена», скачивать PSD). Только русский язык (все строки собраны в одном модуле, чтобы позже можно было добавить другие). Адаптивная вёрстка: **телефон переводчика обязателен**, полноценное редактирование таблицы с телефона.

Стек: React + Vite, TanStack Query (кэш, опрос, ETag), маршрутизация, свой небольшой набор компонентов.

## 1. Экраны

### 1.1 Вход
Логин и пароль, имя устройства (подставляется автоматически из user-agent, можно изменить). Токен хранится в httpOnly-cookie, повторно вводить пароль не нужно ~90 дней.

### 1.2 Проекты и главы
Переключатель проекта, список глав с тремя индикаторами прогресса: «клин N/M», «перевод N/M», «затайплено N/M». Кнопка настроек проекта (язык, направление чтения, настройки PSD).

### 1.3 Экран главы
- Сетка карточек страниц: миниатюра, номер, бейджи состояния («есть клин / нет клина», «перевод 5/8», флажки), отметка «затайплена», бейдж **«разметка изменилась»** (если `markup_changed_for_me`).
- Фильтры: только неготовые, только с флажками, только готовые к тайпу.
- Верхняя панель: **«Скачать PSD»** и статус экспорта (см. 1.5).

### 1.4 Страница (главный экран)

**Десктопная раскладка.** Слева просмотр страницы, справа таблица; граница между ними двигается.

*Просмотр страницы:* переключатель `raw / clean`, чекбокс «показать пометки» (слой notes поверх), зум и перемещение, «вписать», показать/скрыть номера. Поверх **raw** рисуются цветные номера по типам (как в десктопе: те же цвета и подписи); на clean текста нет, поэтому номера там по умолчанию скрыты, но их можно включить. Клик по боксу выбирает строку таблицы, клик по строке подсвечивает бокс и центрирует его.

*Таблица:* колонки «№ · тип · оригинал · перевод · состояние · комментарий / флажок».
- `оригинал` и `перевод` — редактируемые многострочные поля с автоувеличением высоты.
- Навигация: `Tab` — следующее поле, `Enter` — перейти к переводу следующего объекта, `Shift+Enter` — перенос строки, `Ctrl+↑/↓` — между объектами, `Alt+←/→` — между страницами.
- Состояние: значок и меню «Переведено / Пусто / Пропустить (не переводим) / Нечитаемо». Состояние `translated` выставляется автоматически при вводе текста (правила — `01-data-model.md` §3.3).
- Флажок «проверь разметку / непонятно» и поле комментария (одна строка с раскрытием).
- Раздел «Удалено» (сворачиваемый): объекты, убранные клинером, с их переводом; их можно читать и править.
- **Копирование для тайпера.** В PSD текстовых слоёв в MVP нет, поэтому текст тайпер берёт отсюда: кнопка «Копировать» у каждого перевода и «Копировать всё» для страницы (по порядку чтения, формат `1. текст`, по абзацу на объект; `пропущено` и `нечитаемо` помечаются в скобках). Номера в списке совпадают с номерами боксов на странице.
- Кнопка «Затайплена» (переключатель) и «Скачать PSD этой страницы».
- **Баннер «Разметка изменилась»** при открытии страницы, если `markup_rev` новее просмотренного: список изменений из `revisions` (добавлено/перемещено/удалено/изменён клин), кнопка «Понятно» (`PUT /pages/{id}/seen`).

**Мобильная раскладка** (ширина < 768 px):
- Вверху сворачиваемый просмотр страницы с pinch-zoom; нажатие на бокс прокручивает к карточке объекта.
- Объекты — вертикальные карточки: заголовок (номер, тип), оригинал (сворачиваемый, по нажатию редактируется), поле перевода, чип состояния, флажок, комментарий.
- Нижняя панель: предыдущая/следующая страница и номер, «Затайплена».
- Никакой широкой таблицы на телефоне.

### 1.5 Экспорт
Панель на экране главы и на странице:
- чекбокс «только готовые страницы» (по умолчанию включён) и переключатель «включить неготовые»;
- **выбор слоёв:** `Raw`, `Clean`, `Notes` — активные чекбоксы (по умолчанию включены); `Text` — **выключенный и неактивный** чекбокс, включить его нельзя (подсказка: «Текстовые слои появятся позже. Текст копируйте из перевода на странице»);
- кнопка «Скачать»: создаёт задание, показывает прогресс по страницам (опрос), по готовности скачивает zip;
- статус актуальности (`GET /chapters/{id}/export-status`): «последний экспорт актуален» или «устарел: N страниц изменилось» с перечнем страниц и причин (клин, пометки, настройки слоёв). Правки перевода и разметки экспорт не устаревают: текста в PSD нет. Рядом с каждой страницей на экране главы — отметка «изменилась после экспорта»;
- ошибки по страницам из `errors` выводятся понятным текстом.

### 1.6 Настройки
- **Устройства:** список сессий (`GET /me/sessions`), отзыв.
- **Пароль:** смена пароля.
- **Проект:** форма настроек PSD: видимость слоя Raw и прозрачность Notes. Остальные поля `PsdSettings` (шрифт, DPI, размеры, отступы, цвет) зарезервированы под текстовые слои и в интерфейсе скрыты.

## 2. Сохранение, опрос и конфликты

- **Автосохранение:** при выходе из ячейки и после паузы ~800 мс. Индикатор «сохранено / сохраняется / ошибка» у каждой строки.
- **Черновики:** несохранённый текст держится в `localStorage` по ключу объекта; при перезагрузке страницы восстанавливается и досылается. Очищается после успешного PATCH.
- **Нет связи:** баннер «нет соединения», правки остаются в черновиках, повторные попытки с нарастающей паузой; ничего не теряется.
- **Опрос:** страница — каждые 15 с (ETag, `304` почти бесплатны), экран главы — каждые 30 с, только пока вкладка видима. Чужие изменения в полях, которые вы сейчас **не** редактируете, подтягиваются тихо; изменение в поле, которое вы редактируете, не затирает ваш ввод.
- **Конфликт (`409 FIELD_CONFLICT`):** диалог «Пока вы писали, это поле изменил <имя>»: показываются обе версии, кнопки «Оставить мою», «Принять его», «Объединить вручную» (поле с обоими текстами).
- После PATCH всегда используется актуальный `text_ver` из ответа.

## 3. Состояния и качество

- Пустые и загрузочные состояния для всех экранов; ошибки сети и `401` (возврат на вход с сохранением адреса).
- Картинки грузятся лениво; миниатюры для сетки, полноразмерные только на странице; `immutable`-кэш делает повторные открытия мгновенными.
- Доступность: фокус-порядок, `aria-label` на русском, достаточный контраст, не опираться только на цвет (у типов объектов разные подписи).
- Производительность: страница с 100 объектами остаётся отзывчивой; таблица не перерисовывается целиком при вводе в одну ячейку.

## 4. Тесты
Компонентные (таблица, диалог конфликта, панель экспорта), e2e на Playwright по ключевым сценариям (вход → перевод страницы → экспорт; конфликт двух вкладок; мобильный вьюпорт).
