# STATUS

Обновляется после каждого среза. Последнее обновление: **M1 завершён** (2026-11-17).

## Сделано
- **M0. Фундамент:** pnpm workspaces, TS strict, ESLint + Prettier, vitest (projects); `packages/contract` — zod-схемы, ошибки, OpenAPI, UUID v7, SHA-256, `canonicalJson`, `psd_input_hash`, авто-порядок, геометрия, статусы, правила PATCH, diff разметки, заголовки PNG/JPEG/WebP, фикстуры.
- **M1. Сервер** (`apps/server`): SQLite (`node:sqlite`, WAL) + миграции с бэкапом перед новой миграцией; авторизация (argon2id, сессии по устройствам, cookie/Bearer, CSRF-заголовок, лимит попыток, desktop-only эндпоинты); blobs (потоковая запись, проверка хэша, сигнатуры, размеров, лимиты пикселей, immutable-кэш); каталог проектов/глав с вычисляемыми статусами и ETag/304; sync (одна транзакция, ревизии разметки, мягкое удаление/восстановление, `REVISION_CONFLICT`, `BLOBS_MISSING`, `RAW_IMMUTABLE`, `SIZE_MISMATCH`, идемпотентность); PATCH объектов (конфликты по полям, история, правила `state`), `typed`, `seen`; экспорт (очередь в БД, воркер по странице, потоковый zip, manifest, `errors.json`, актуальность по `psd_input_hash` с причинами, очистка по сроку); `komaflow-admin` (пользователи, сессии, `backup`, `dump-text`, `gc-blobs`, `seed --fixtures`); отдача собранного веба (CSP, SPA fallback).
- **M1. PSD** (`packages/psd`): выбор слоёв и страниц, запись растрового PSD через ag-psd (Notes / Raw скрыт / Clean, композит), кодек на sharp. Текстовых слоёв нет (API отвечает 422 на `text: true`).
- **M1. Веб** (`apps/web`): вход, проекты и главы (прогресс клин/перевод/затайплено, создание проекта), экран главы (карточки, бейджи, фильтры, «изменилась после экспорта»), страница (просмотр raw/clean/пометки, зум/пан/pinch, номера по типам с разной формой, таблица с автосохранением и черновиками, клавиши, конфликт-диалог, раздел «Удалено», «Копировать»/«Копировать всё», «Затайплена», баннер изменений разметки), мобильная раскладка (карточки, нижняя панель), панель экспорта (галочка «Текст» выключена и неактивна, прогресс, ошибки, актуальность), настройки (устройства, пароль, проект и PSD).
- **M1. Сид:** `pnpm seed` и `komaflow-admin seed --fixtures` публикуют фикстурную главу через настоящее API.
- **Спайки:** S1 — харнес и отчёт (`docs/spikes/S1-report.md`), автоматическая часть пройдена; S3 — харнес `tools/spikes/s3-arm/` и шаблон отчёта, замеры на Windows.

### Проверено вручную в браузере (машина разработки)
Вход → глава → перевод страницы с клавиатуры (Enter/Shift+Enter), автосохранение; конфликт двух вкладок → диалог → «Объединить вручную» сохранилось; мобильный вьюпорт 375×812 (карточки, нажатие на бокс прокручивает к карточке); экспорт из главы (zip скачивается, статус «актуален»); баннер «Разметка изменилась» после sync и «Понятно».

## Известные проблемы
- e2e на Playwright не настроены: ключевые сценарии проверены вручную (см. выше) и компонентными тестами.
- Пик RSS при экспорте не ограничивается явно; одна страница 2000×3000 ≈ 120 МБ буферов. Подтвердить на Pi (S3).
