# S1b — проверка текстовых слоёв в Photoshop (для тайпера)

1. Экспортируйте главу из веба с включённой галочкой «Текст».
   Для быстрой проверки подойдут демо-данные: `KOMAFLOW_DEV=1 pnpm --filter @komaflow/server admin -- seed --fixtures`, затем экспорт главы 1.
2. Откройте любой `.psd` из архива. Запишите версию Photoshop.

- [ ] Photoshop спрашивает «Обновить текстовые слои?» → нажмите **«Обновить»**. Файл открылся без ошибок.
- [ ] Порядок слоёв: `Notes`, `Raw` (скрыт), группа `Text`, `Clean`.
- [ ] В группе `Text` слои `01_bubble`, `02_…` в порядке чтения; текст — перевод из веба, кириллица отображается.
- [ ] Инструмент «Текст» открывает слой: это абзацный текст в рамке, размер рамки ≈ пузырь с отступом.
- [ ] Шрифт — тот, что указан в настройках проекта (по умолчанию ArialMT). Если шрифта нет в системе, Photoshop предложит замену — это нормально.
- [ ] Повёрнутый бокс даёт повёрнутый текст.
- [ ] Перенос строк из перевода (Enter в вебе) сохраняется.
- [ ] «Сохранить как» PSD и повторное открытие работают.

Результат и скриншот панели слоёв впишите в `docs/spikes/S1-report.md`, раздел «S1b». Если хотите свой шрифт по умолчанию, пришлите его PostScript-имя: Photoshop → Текст → шрифт, или «Шрифты» в Windows → свойства файла.
