# S1 — проверка PSD в Photoshop (для тайпера)

Файлы: `tools/spikes/s1-psd/out/*.psd` (пересоздать: `pnpm --filter @komaflow/tools s1`). Запишите версию Photoshop.

Для **V1-2000x3000-all**, **V1-fixture-800x1200** и каждого **V2-***:
- [ ] файл открывается без ошибок и предупреждений;
- [ ] слои: `Notes` сверху, под ним `Raw`, внизу `Clean`; `Raw` скрыт (глаз выключен);
- [ ] `Notes` прозрачный (клин виден под ним), непрозрачность слоя 100 % (в **V4** — 40 %);
- [ ] слои совпадают с размером документа и не сдвинуты;
- [ ] включение `Raw` показывает оригинал, цвета не изменились;
- [ ] «Сохранить как» PSD из Photoshop и повторное открытие работают;
- [ ] `Clean` — обычный слой (не замок «Фон»);
- [ ] скриншот панели слоёв приложен.

Для **V3-1600x10000**: открывается, прокрутка работает. Результаты впишите в `docs/spikes/S1-report.md`, раздел «Photoshop».
