# S1 — растровый PSD: отчёт

**Библиотека:** `ag-psd` 34.2.1, декодер `sharp` 0.34.5 (ADR 0006, 0007). Харнес: `tools/spikes/s1-psd/run.ts`.

## Что проверено автоматически (Windows x64, Node 26.7, машина разработки)
- Порядок `children` в ag-psd — снизу вверх (по коду `psdWriter.addChildren`); генератор передаёт `[Clean, Raw, Notes]`.
- Чтение обратно (`readPsd`): имена, порядок, видимость (`Raw` скрыт), непрозрачность `Notes`, размеры слоёв = документ, текстовых слоёв нет. Golden-тесты: `packages/psd/test/psd.test.ts`, `apps/server/test/exports.test.ts`.
- Композит строится из видимых слоёв (превью в проводнике не пустое); без `Clean` фон прозрачный.

| Вариант | Время | Размер PSD | Слои (сверху вниз) |
|---|---|---|---|
| V1 2000×3000, 3 слоя | 290 мс | 2,0 МБ | Notes > Raw(скрыт) > Clean |
| V2 все 7 комбинаций 1200×1800 | 20–105 мс | 0,3–0,9 МБ | по галочкам |
| V3 1600×10000, 3 слоя | 680 мс | 4,7 МБ | Notes > Raw(скрыт) > Clean |
| V4 Notes 40 % + полупрозрачные пиксели | 100 мс | 0,7 МБ | Notes@40% > Clean |

Пик RSS харнеса за весь прогон — ~600 МБ (накопительно, GC не форсируется). На одну страницу 2000×3000 генерация держит 4 RGBA-буфера по 24 МБ + PSD (~120 МБ). На Orange Pi — повторить в S3.
